# Homebrew Tap for Omni Text

AI-powered text rewriting from any app via global hotkeys.

## Install

```bash
brew tap addison-w/omni-text
brew install --cask omni-text
```

## Update

```bash
brew upgrade --cask omni-text
```

## Uninstall

```bash
brew uninstall --cask omni-text
```

## About

[Omni Text](https://github.com/addison-w/Omni-Text) is a macOS menu bar app that rewrites selected text using AI. Select text in any app, press a hotkey, and get it rewritten instantly. Works with any OpenAI-compatible API provider.
